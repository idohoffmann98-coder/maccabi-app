# צהוב-כחול 🏀💛💙
אפליקציית ווב (PWA) לא רשמית לאוהדי מכבי תל אביב בכדורסל, בעברית. היא מציגה נתונים מכל המפעלים שמכבי משחקת בהם: יורוליג, ליגת העל, גביע ווינר, גביע המדינה וסופרקאפ.

## מקורות הנתונים
| מקור | מה נלקח ממנו |
|---|---|
| ה-API הרשמי של היורוליג | לוח משחקים, תוצאות, Box Score מלא, סגל, טבלה, ומשחקים מעונות קודמות |
| אתר מנהלת ליגת העל (basket.co.il) | לוח משחקים ותוצאות של הליגה, הגביעים והסופרקאפ, טבלת הליגה, ממוצעי השחקנים והקבוצה בליגה |
| האתר הרשמי של מכבי (maccabi.co.il) | עדכוני פציעות: השרת מחפש בכתבות של 75 הימים האחרונים ומחלץ מהן את שם השחקן, סוג הפציעה ומשך ההיעדרות המשוער |

## מה יש באפליקציה
- **מסך בית:** עובדה מגניבה שמתחלפת בכל פתיחה (גם עובדות היסטוריות וגם עובדות שמחושבות מנתוני העונה), המשחק הבא עם ספירה לאחור, השחקנים החמים, המשחק האחרון והמצטיין בו, נתוני הקבוצה ומובילי הקבוצה.
- **משחקים:** לוח המשחקים, תוצאות ו-Box Score מלא לכל משחק.
- **לפני משחק:** פצועים ונעדרים בשתי הקבוצות, מפגשי העבר מול היריבה (2 עונות אחורה), השחקן המוביל במפגש האחרון, והשחקנים החמים בשתי הקבוצות.
- **שחקנים:** ממוצעים לכל שחקן ופרופיל עם נתוני משחק-אחר-משחק.
- **טבלה:** טבלת היורוליג, עם סימון של אזורי הפלייאוף והפליי-אין.
- **התראות פוש:** בתחילת כל משחק, ובסיום מותח (רבע 4, 5 הדקות האחרונות, הפרש קטן מ-10, וגם בהארכה).

## איך הנתונים מתעדכנים
השרת מריץ מתזמן קבוע:

| מתי | מה קורה |
|---|---|
| כל 12 שעות | עדכון שגרתי של לוח המשחקים, הסגל והטבלה |
| 3 שעות לפני משחק | בדיקת נעדרים ופצועים, מפגשי עבר ושחקנים חמים (בונה "תצוגה מקדימה") |
| בשריקת הפתיחה | התראת פוש "המשחק מתחיל" |
| במהלך המשחק | בדיקה של התוצאה בלבד: כל 4 דקות, ומהרבע הרביעי כל 30 שניות. זו קריאה קטנה אחת, לא הזרמה בזמן אמת |
| משחק בליגת העל | מבדיקה שעתיים אחרי שריקת הפתיחה, בודק כל 10 דקות אם התוצאה הסופית פורסמה |
| כשהמשחק נגמר | עדכון מלא של כל הסטטיסטיקה והטבלה, ובניית התצוגה המקדימה למשחק הבא |

**השחקנים החמים:** שחקן נחשב "חם" כשממוצע המדד (PIR) שלו ב-3 המשחקים האחרונים גבוה בלפחות 20% (ולפחות ב-3 נקודות מדד) מהממוצע שלו לאורך העונה.

**פציעות** (שלוש שכבות):
1. **עדכוני המועדון:** כתבות באתר הרשמי של מכבי, למשל "איפה לונדברג עבר ניתוח בעקבות קרע במיניסקוס… כחודש". כל פציעה מוצגת עם קישור לכתבה. אם השחקן שיחק אחרי מועד העדכון, הפציעה יורדת מהרשימה.
2. **זיהוי אוטומטי:** שחקן מהסגל שלא שיחק במשחקי היורוליג האחרונים מופיע כנעדר.
3. **עדכון ידני** בעמוד הניהול `/admin`. העמוד מוגן בטוקן, ועדכון ידני גובר על המקורות האוטומטיים.

**ליגת העל: מה עוד לא נתמך.** אתר המנהלת לא מציג Box Score למשחק בודד, ולכן במשחקי הליגה מוצגים תוצאה, ממוצעים וקישור לדף המשחק באתר המנהלת. בנוסף, אין מקור לתוצאה חיה במשחקי הליגה, ולכן התראת "סיום מותח" נשלחת רק במשחקי יורוליג. התראת "המשחק מתחיל" נשלחת בכל המפעלים.

## הרצה מקומית
דרוש Node.js בגרסה 20 ומעלה.
```bash
npm install
```
```bash
ADMIN_TOKEN=סיסמה-שלך npm start
```
אחרי זה פותחים בדפדפן את http://localhost:3000.

## העלאה לאינטרנט
האפליקציה צריכה **שרת שרץ כל הזמן**, כי המתזמן צריך לפעול גם כשאף אחד לא פותח אותה. התראות פוש דורשות **HTTPS**. שירותים מתאימים: Railway, Fly.io, או שרת VPS קטן. לא מומלץ להשתמש בשכבה החינמית של Render, כי השרת שם "נרדם" כשאין גלישה והמתזמן מפסיק לעבוד.

משתני סביבה:
| משתנה | תיאור |
|---|---|
| `ADMIN_TOKEN` | סיסמה לעמוד הניהול (חובה לשנות!) |
| `VAPID_SUBJECT` | `mailto:` עם המייל שלך (דרישה של תקן Web Push) |
| `DATA_DIR` | תיקייה לשמירת הנתונים. בשירותי ענן כדאי לחבר אליה Volume קבוע, כדי שההרשמות להתראות לא יימחקו |
| `PORT` | פורט (ברירת מחדל: 3000) |

## התקנה בטלפון
- **אנדרואיד (Chrome):** תפריט ← "הוספה למסך הבית".
- **אייפון (Safari, iOS 16.4 ומעלה):** שיתוף ← "הוספה למסך הבית". באייפון התראות פוש עובדות רק כשפותחים את האפליקציה מהאייקון במסך הבית.

אחרי ההתקנה לוחצים על 🔔 ומפעילים את ההתראות. אפשר לבדוק שהן עובדות עם כפתור "שליחת פוש ניסיון" בעמוד הניהול.

## מבנה הקוד
```
src/
  server.js      ← שרת Express ו-API
  scheduler.js   ← המתזמן: לפני משחק, תחילת משחק, סיום מותח, אחרי משחק
  data.js        ← משיכת נתונים, מטמון ותצוגה מקדימה למשחק
  euroleague.js  ← לקוח ל-API של היורוליג
  stats.js       ← חישובים: ממוצעים, שחקנים חמים, נעדרים, מפגשי עבר
  facts.js       ← עובדות מגניבות (קבועות ומחושבות)
  hebrew.js      ← שמות קבוצות ושחקנים בעברית
  push.js        ← התראות פוש (VAPID)
public/          ← האפליקציה (HTML/CSS/JS, Service Worker, Manifest)
data/            ← הנתונים השמורים (נוצרים אוטומטית)
```

## הערות
- זו אפליקציית אוהדים לא רשמית, ואין לה קשר למועדון או ליורוליג. הנתונים מגיעים מהפיד הציבורי של היורוליג.
- שחקן חדש שמצטרף לסגל יוצג בשמו באנגלית עד שמוסיפים לו שם בעברית ב-`src/hebrew.js`.
